# Observatorio SBAP · Minería

Página interactiva con los pronunciamientos del Servicio de Biodiversidad y Áreas Protegidas (SBAP) en proyectos mineros en calificación en el SEIA (DIA y EIA), entre febrero y octubre de 2026.

- Fuente: expedientes de evaluación del SEIA (seia.sea.gob.cl), consulta del 08-10-2026.
- Universo: sector productivo «Minería», estado «En calificación».
- Abre `index.html` en el navegador o visita la página publicada con GitHub Pages.

Elaborado para SONAMI · Sociedad Nacional de Minería.
