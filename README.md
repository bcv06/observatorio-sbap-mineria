# Observatorio SBAP · Minería

Página interactiva con los pronunciamientos del Servicio de Biodiversidad y Áreas Protegidas (SBAP) en proyectos mineros en calificación en el SEIA (DIA y EIA), desde febrero de 2026.

- Fuente: expedientes de evaluación del SEIA (seia.sea.gob.cl) y oficios firmados (infofirma.sea.gob.cl), consulta del 16-11-2026. Se actualiza cada semana.
- Universo: sector productivo «Minería», estado «En calificación» a la fecha de la consulta.
- Los temas se asignan por palabras clave: la clasificación es aproximada.
- Abre `index.html` en el navegador o visita la página publicada con GitHub Pages.

Elaborado para SONAMI · Sociedad Nacional de Minería.
